# 자모 점프

두 글자 단어로 자음과 모음을 타고 점프해서 초록 칸에서 깃발까지 가는 한글 퍼즐입니다.
웹 예능 〈네 가지 소원〉 EP.2 3회전 데스매치의 규칙을 바탕으로 만들었습니다.

https://pyungjae9492.github.io/hangul-sulraejabgi/

## 규칙

- 단어의 두 글자를 몇 번이든 다시 쓸 수 있고 점프 횟수에도 제한이 없습니다. 두 글자 모두 한 번 이상은 써야 합니다.
- 한 글자는 지금 밟고 있는 칸의 자음이 그 글자에 들어 있을 때만 쓸 수 있습니다.
- 같은 자음이 여러 칸에 놓일 수 있고, 깃발 칸에도 자음이 있을 수 있습니다.
- 자음 점프: 같은 글자의 다른 자음 칸으로 이동합니다.
- 모음 점프: 모음의 획 방향으로 획 개수만큼 이동합니다. ㅡ ㅣ ㅢ는 모음 점프가 없습니다.
- 조건: 모음 점프만, 자음 점프만, 모든 칸 밟기, N번 안에, 딱 N번.
- 방송 문제 Round 3(유광), Round 4(암탉)를 테스트로 고정해 두었습니다. Round 4는 5단계 보스로 그대로 씁니다.

## 구성

- 처음 화면에서 세 가지 모드를 고릅니다.
  - **오늘의 도전**: 하루 한 번, 쉬움 60초 → 보통 90초 → 어려움 120초 3라운드. 시간 초과면 끝나고, 깬 라운드마다 별 1개. 결과를 공유하면 하루 2번까지 이어서 할 수 있습니다. 문제는 한국 시간 날짜를 시드로 만들어 모든 사람이 같은 판을 받습니다.
  - **무한 모드**: 난이도를 골라 끝없이 풉니다. 연속 정답 기록이 남고, 한 번 나온 대표 정답은 다시 나오지 않게 피합니다.
  - **20단계 등반**: 미리 만들어 검수한 고정 스테이지.
- 실시간 문제 생성은 `gen.js`가 맡습니다. 휴대폰에 `fam.js`(친숙한 단어 2,670개)를 함께 실어 판 하나를 수 ms 안에 만듭니다.
- 처음 들어오면 스플래시 다음에 실제 게임판에서 따라 하는 튜토리얼이 나옵니다.
- 스테이지 20개를 순서대로 올라갑니다. 5, 10, 15, 20은 정답이 1~2개뿐인 보스 스테이지입니다.
- 별: 힌트 없이 3개, 첫 글자 힌트 2개, 정답 보기 1개. 진행은 브라우저에 저장됩니다.
- 스테이지는 `scripts/build-stages.js`로 `stages.js`에 미리 만들어 둡니다.

가정(영상 미확인): ㅐ/ㅔ/ㅒ/ㅖ는 ㅏ/ㅓ/ㅑ/ㅕ와 같은 이동, ㅚ/ㅟ/ㅙ/ㅞ는 ㅗ/ㅜ/ㅘ/ㅝ와 같은 이동,
쌍자음은 기본 자음 칸으로 취급. `engine.js`의 `VOWEL_MOVES`, `BASE`에서 고칩니다.

## 실행

```bash
python3 -m http.server 5173   # http://localhost:5173
node --test test/engine.test.js
```

## 단어 목록

`words.js`는 `scripts/build-words.py`로 만듭니다.

- `WORDS` (약 1.5만): 출제와 AI 답에 쓰는 일상 명사. [hunspell-dict-ko](https://github.com/spellcheck-ko/hunspell-dict-ko)(MPL/GPL/LGPL)에서 추출.
- `WORDS_EXTRA` (약 5.7만): 정답 판정에만 쓰는 나머지 2글자 명사. [표준국어대사전 표제어 DB](https://github.com/korean-word-game/db)(2018)에서 추출.
