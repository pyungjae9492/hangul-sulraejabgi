# 자모 점프

두 글자 단어로 자음과 모음을 타고 점프해서 초록 칸에서 깃발까지 가는 한글 퍼즐입니다.
웹 예능 〈네 가지 소원〉 EP.2 3회전 데스매치의 숨바꼭질 게임을 차용해 만들었습니다.

https://pyungjae9492.github.io/hangul-sulraejabgi/

## 규칙

- 글자는 지금 밟고 있는 칸의 자음이 그 글자에 들어 있을 때만 쓸 수 있습니다.
- 자음 점프: 같은 글자의 다른 자음 칸으로 이동합니다. 받침이 없거나 자음이 한 종류면 없습니다.
- 모음 점프: 모음의 획 방향으로 획 개수만큼 이동합니다. ㅡ ㅣ ㅢ는 없습니다.
- 단어의 글자는 순서와 횟수에 상관없이 다시 쓸 수 있고, 깃발에 닿으면 끝납니다.
- 판마다 붙는 조건: 모음 점프만, 자음 점프만, 두 글자 모두 쓰기, 모든 칸 밟기(다시 밟아도 됨), 모든 칸 한 번씩만, N번 안에, 딱 N번.
- 방송 문제 Round 3(유광), Round 4(암탉)는 테스트로 고정해 두었습니다.

가정(영상 미확인): ㅐ/ㅔ/ㅒ/ㅖ는 ㅏ/ㅓ/ㅑ/ㅕ와 같은 이동, ㅚ/ㅟ/ㅙ/ㅞ는 ㅗ/ㅜ/ㅘ/ㅝ와 같은 이동,
쌍자음은 기본 자음 칸으로 취급합니다.

## 모드

- **오늘의 도전**: 하루 한 번 20단계를 올라갑니다. 단계마다 제한 시간이 있고 시간 초과면 끝납니다.
  5·10·15·20단계는 보스이고, 보스를 넘을 때마다 별 하나(최대 4개). 결과를 공유하면 하루 2번까지 이어서 할 수 있습니다.
  - 보스는 `bosses.js`에 미리 만들어 검수한 풀에서 날짜별로 돌려 씁니다(외길 24, 구멍 난 고리 5, 징검돌 8, 미로 5).
  - 나머지 16단계는 한국 시간 날짜를 시드로 그 자리에서 만들어, 모든 사람이 같은 판을 받습니다. 단계가 오를수록 난이도가 올라갑니다(입문 → 쉬움 → 보통 → 까다로움 → 어려움).
- **무한 모드**: 난이도를 골라 끝없이 풉니다. 연속 정답 기록이 남습니다.

## 실행과 데이터

```bash
python3 -m http.server 5173   # http://localhost:5173
node --test test/engine.test.js
node scripts/build-bosses.js 24 [슬롯]   # 보스 풀 만들기
node scripts/recheck-bosses.js         # 규칙이 바뀐 뒤 보스 풀 다시 검사
```

- `words.js`: 정답 판정용 2글자 명사. `WORDS`(약 1.5만, [hunspell-dict-ko](https://github.com/spellcheck-ko/hunspell-dict-ko))와 `WORDS_EXTRA`(약 5.7만, [표준국어대사전 표제어 DB](https://github.com/korean-word-game/db)).
- `fam.js`: 출제용 친숙한 단어 2,670개. [FrequencyWords](https://github.com/hermitdave/FrequencyWords)(CC-BY-SA 4.0) 자막 빈도로 고릅니다.
